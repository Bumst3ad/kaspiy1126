# PLAN.md — Smart Caspian Transit

## План: Вертикальный срез P0 (Золотой путь демо)

### 1. Цель среза
Реализовать 3-минутный «золотой путь» MVP согласно разделу 2 AGENTS.md:
1. Полноэкранная тёмная карта Каспия (порты, канал ВКМСК, суда, статусы).
2. Выбор судна MV Demo-01 → расчёт риска мели (осадка vs прогнозная глубина ВКМСК) → алерт с временем риска.
3. «Синхронизировать слот» (Caspian Sync-Slot): трёхсторонняя панель (РЖД / порт / судно) → переход на Махачкалу с пересчётом времени, стоимости и CO₂.
4. Карточка груза (цифровой двойник): таймлайн, ESG-сравнение (море vs авто vs перенаправление), pre-clearance статус.

### 2. Задачи (Пошагово)
1. **Инфраструктура и стек:**
   - Настройка TypeScript (strict, без `any`), Tailwind (маппинг токенов), ESLint, Vitest, check-design.
   - Единый источник правды: `src/styles/tokens.css` (только здесь разрешены hex).
2. **Данные (`src/data/`):**
   - `assumptions.ts` (допущения: осадка 4.2–4.5м, сгон 40–60см, потери $15 000/сут, порог слота 3ч).
   - `emissionFactors.ts` (коэффициенты GLEC / ISO 14083).
   - `ports.ts`, `vessels.ts`, `routes.ts` (вымышленные названия: «MV Demo-01», порты с точными координатами).
3. **Доменная логика и тесты (`src/domain/`):**
   - `underkeelClearance.ts` + `underkeelClearance.test.ts` (глубина − осадка − запас безопасности).
   - `syncSlot.ts` + `syncSlot.test.ts` (расчёт трёхстороннего слота и перехода на Махачкалу).
   - `esgCalculator.ts` + `esgCalculator.test.ts` (расчёт выбросов CO₂ по методике GLEC).
4. **Пользовательский интерфейс (`src/ui/`):**
   - Тёмная полноэкранная карта (Esri World Dark Gray с мелкой атрибуцией `text-2`).
   - Парящие стеклянные панели (`.glass-panel`, не более 3 с blur).
   - Иконки `lucide-react` (stroke 1.5, без цветных подложек, без эмодзи).
   - Кнопка «Синхронизировать слот» с трёхсторонним согласованием.
5. **Верификация:**
   - `npm run verify` (typecheck && lint && test && check:design && build) → 0 ошибок.
   - Проверка в браузере на 1440×900 и 1920×1080.
   - Коммит `feat(p0): complete golden path MVP with sync-slot and esg`.

### Критерий «Готово»
- `npm run verify` завершается с кодом 0 (нет ошибок типов, линтера, тестов vitest, нарушений дизайна и сборки).
- Пройден золотой путь: штатный режим → сгон ВКМСК (осадка 4.2м vs глубина 3.85м) → Sync-Slot на Махачкалу → карточка груза с ESG.
- Консоль браузера чистая.
