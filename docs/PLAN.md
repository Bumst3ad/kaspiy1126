# PLAN.md — Smart Caspian Transit

## План: Точечные исправления данных и вёрстки (БЕЗ новых фич)

### 1. Цель
Устранить выявленные расхождения в доменных данных и довести вёрстку до безупречного состояния на экранах 1920×1080, 1440×900, 1366×768 согласно AGENTS.md (0, 5, 6, 8).

### 2. Задачи (Пошагово)

#### ЧАСТЬ 1. Данные (domain logic):
1. **Запас под килем (UKC):**
   - Формула: `глубина - осадка`.
   - Логика:
     - `запас < 0` → `critical` («посадка на мель»);
     - `0 <= запас < 0.5 м` → `warn` («проход под контролем»);
     - `запас >= 0.5 м` → `ok` («запас в норме» / «штатно»).
   - Единое значение во всех карточках, бейджах и описаниях.
2. **CO₂ (модуль `emissions.ts` / `esgCalculator.ts`):**
   - Функция: `экономия = авто − (море + ж/д)`.
   - Убрать любой хардкод (995.8, -81.5%), пересчитывать строго динамически при переключении сценариев/слота.
3. **Единый объект параметров Sync-Slot:**
   - Объект `SYNC_SLOT_CONFIG` (`RZD-Slot-A17`, `B-4`, `KR-2 (32 т)`, `LOC-41`, Махачкала 6.8 м).
   - Удалить дублирующую кнопку действия из карточки судна (`SyncSlotPanel`), оставить единственную кнопку в панели решений (`DecisionMatrix`).
4. **Дельты в карточке судна:**
   - Четкие подписи «Если ничего не делать» и «С выбранным решением»; значения брать из выбранных объектов сценариев.
5. **Манифест ТН ВЭД:**
   - Заменить `3901 20 900 0` на `3901 10 900 0` (ПВД низкой плотности), добавить пометку в `assumptions.ts` («проверить у декларанта»).
6. **Вымышленные компании:**
   - `СИБУР` → `ООО «Полимер-Демо»`
   - `ТЛЦ «Белый Раст»` → `Терминал Демо-Север`
   - `Amirabad Petrochemical Complex` → `Demo Petrochemical Co.`
   - Убрать упоминания `СКЖД` (оставить `РЖД` / полигон).
7. **Атрибуция карты:**
   - Мелкая видимая атрибуция `Esri / Leaflet` (`text-2`) без флага.

#### ЧАСТЬ 2. Вёрстка (CSS и UI):
1. **Левая колонка:**
   - Сетка `grid-rows-[minmax(260px,1fr)_auto]`.
   - Строку метрик вынести в шапку таймлайна компактно.
   - Убрать лишние чипы под плеером, исключить обрезание на 1366×768.
2. **Карта:**
   - `fitBounds` на канал с padding, подпись «0 км · Астрахань» не обрезается.
   - Кнопка «Канал / Весь Каспий».
3. **Заголовок Sync-Slot в DecisionMatrix:**
   - В одну строку: бейдж «Рекомендовано», «Формулы» — иконка-кнопка.
4. **График HydroChart:**
   - Подпись «Осадка» справа над линией, «ОКНО РИСКА» по центру над зоной.
   - Шрифты осей $\ge 12\text{px}$, полоса P10–P90 полупрозрачным токеном.
5. **Тултипы Leaflet:**
   - Стиль `.glass-panel`, без белой рамки, шрифт 13px, monospace только для чисел.
6. **Правая колонка:**
   - Внутренний скролл, sticky-заголовок, кнопка «Применить» видна без скролла в сценарии «Сгон» на 1366×768.
