# Logistics Dashboard (Single Window) Skill

Этот навык описывает создание представительского веб-интерфейса «Единое окно логиста» с интерактивной картой Каспия и цифровым двойником груза.

## 1. Структура интерфейса
Дашборд должен быть визуально эффектным, в темной теме ситуационного центра («Command Center»):
1. **Верхний бар (Header):**
   - Логотип: **Smart Caspian Transit** (МТК «Север-Юг»).
   - Статус системы: Live погода в Каспийском регионе, общее число активных судов/контейнеров, индикатор заторов.
   - Кнопка симуляции форс-мажора: «Эмулировать шторм в Энзели» (для демонстрации жюри!).
2. **Центральная зона: Интерактивная карта (Leaflet):**
   - Базовая карта с темными тайлами (CartoDB DarkMatter).
   - Полигоны и маркеры портов: Астрахань, Оля, Махачкала, Актау, Туркменбаши, Баку, Энзели, Амирабад.
   - Цвет маркера порта: Зеленый (штатный режим), Желтый (повышенная нагрузка), Красный (затор / неблагоприятная погода).
   - Линии маршрутов (Polylines): транскаспийские морские пути, восточный и западный ж/д коридоры.
   - Анимированные маркеры судов и контейнерных составов.
3. **Правая панель (Инспектор цифрового двойника груза):**
   - Выбор ID контейнера/партии (например, `CASP-RU-IR-884`).
   - Маршрут: Москва -> Махачкала -> Энзели -> Бендер-Аббас.
   - Предиктивный бейдж задержки: `+14.5 часов (Риск: ВЫСОКИЙ)`.
   - Фактор задержки: `Шторм в Южном Каспии (высота волны 3.2м)`.
   - Карточка Pre-clearance: Статус `PRE_CLEARED` (Зеленый коридор активен).
   - ESG-виджет: Текущий углеродный след: `1.2 т CO2` (Экономия 68% по сравнению с автоперевозкой).
   - Кнопка динамического рероутинга: *"Переключить на Восточный ж/д коридор через Актау/Серахс"* (с пересчетом времени и цены).

## 2. Ключевые библиотеки
- React 18 / Vite
- `leaflet` + `react-leaflet` (быстрая и стабильная картография без платных API ключей Mapbox/Google)
- `lucide-react` (иконки: корабль, поезд, грузовик, лист/экология, предупреждение, щит)
- `tailwind-css` (быстрая верстка, стильные карточки со стеклянным эффектом `backdrop-blur`).
