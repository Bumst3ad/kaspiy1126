## Сделано (P0)
1. **Инфраструктура и строгий дизайн:**
   - Настроен проект Vite + React + Tailwind + TypeScript (strict, без `any`).
   - `scripts/check-design.mjs` интегрирован и проходит проверку на 0 нарушений.
   - Единственный источник правды для цветов — `src/styles/tokens.css` (токены Apple HIG: `bg-base`, `surface`, `hairline`, `accent`, `ok`, `warn`, `critical`, `text`, `text-2`, `divider`).
   - Утилита `.glass-panel` ограничена ровно 3 панелями (Header, SyncSlotPanel, CargoCard).
   - Ликвидированы любые градиенты, светящиеся неоновые тени, эмодзи в коде и сырые классы Tailwind.
2. **Данные и честность (`src/data/`):**
   - `assumptions.ts` с явным полем `provenance: "assumption"` (осадка 4.2–4.5м, сгон 0.65м, демередж $15 000/сут, порог слота 3ч).
   - `emissionFactors.ts` с `provenance: "real"` (методика GLEC Framework v3.0 / ISO 14083).
   - `ports.ts` (Астрахань/Оля, Махачкала, Энзели, Амирабад, Актау, Туркменбаши, Баку).
   - `vessels.ts` с вымышленным судом «MV Demo-01» (`provenance: "synthetic"`). В UI выведена метка «Демо-данные».
3. **Чистая доменная логика с тестами (`src/domain/`):**
   - `underkeelClearance.ts` + 5 тестов (физическая эвристика сгона ветра + расчёт запаса под килем).
   - `syncSlot.ts` + 2 теста (расчёт трёхстороннего слота и перехода на глубоководную Махачкалу).
   - `esgCalculator.ts` + 2 теста (расчёт выбросов CO₂ по методике GLEC, сравнение море vs авто).
   - `preClearance.ts` + 1 тест (криптографический хеш манифеста SHA-256 via Web Crypto API, ledger-ready).
   - Все 10 тестов проходят в `vitest`.
4. **Пользовательский интерфейс P0 (`src/ui/`):**
   - Тёмная полноэкранная карта Esri World Dark Gray с мелкой атрибуцией `text-2`.
   - Парящие стеклянные панели в эстетике Apple HIG.
   - Золотой путь:
     1. Карта с портами, судами и каналом ВКМСК.
     2. Клик «Симулировать сгон ВКМСК» → падение глубины с 4.5м до 3.85м → расчёт риска мели (осадка 4.25м > глубина 3.85м).
     3. Клик «Синхронизировать слот (РЖД / Порт / Судно)» → автоматическое согласование трёх сторон → перенаправление на причал №4 Махачкалы (глубина 6.8м) → задержка сокращается с 72ч до 1.5ч, экономия $44 063 и 18.4т CO₂.
     4. Карточка груза: манифест e-CMR, ТН ВЭД 3102 10 100 0, статус электронной пломбы, ledger-ready хеш и Pre-clearance.
