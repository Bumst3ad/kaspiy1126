> **Трек 3, Кейс 2:** «Smart Caspian Transit»  
> **Режим работы:** 100% автономный офлайн-режим (Localhost, без обязательных внешних сетевых запросов).

## 1. Команды запуска и проверки

Проект разработан на **Vite + React + Tailwind CSS + TypeScript (strict)** без лишних зависимостей.

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального dev-сервера (по умолчанию http://localhost:5173/)
npm run dev

# 3. Производственная сборка и локальный предпросмотр
npm run build
npm run preview

# 4. Комплексная верификация качества кода (Definition of Done)
npm run verify
# Включает: typecheck (tsc --noEmit) && lint && test (vitest) && check:design && build
```

Дополнительные команды:
- `npm run test` — запуск юнит-тестов и хаос-матрицы в Vitest (`src/domain/`).
- `npm run check:design` — строгий линтер дизайн-токенов Apple HIG (запрет «дизайн-слопа», градиентов, сырых hex и неоновых цветов).

## 2. Что реально работает vs Что симуляция

В соответствии с правилами честности хакатона и разделом 6 `AGENTS.md`, система строго разделяет математический расчёт и демо-данные:

| Компонент | Что реально работает (Domain-логика) | Что симуляция / Демо-допущение (`src/data/`) |
|---|---|---|
| **Гидрологический профиль ВКМСК** | • Физическая эвристика: гидродинамический базис + ветровой сгон + наносы паводка.<br>• Расчёт запаса под килем: $\text{UKC} = \text{глубина} - \text{осадка}$.<br>• Доверительный интервал неопределенности P10–P90.<br>• Нормальная аппроксимация вероятности посадки на мель $P(\text{глубина} < \text{осадка}) = \Phi\left(\frac{\text{осадка} - \mu}{\sigma}\right)$. | Метеорологические сценарии (направление/скорость ветра) задаются детерминированными снапшотами (seed). |
| **Caspian Sync-Slot (РЖД ⇄ Порт ⇄ Судно)** | • Трёхсторонняя координация на единой оси времени с технологическими буферами (швартовка $\to$ кран $+1.0\text{ч}$, кран $\to$ поезд $+0.5\text{ч}$).<br>• Детекция срыва слота при задержке $>6\text{ ч}$. | Идентификаторы ресурсов обезличены (`Нитка A-17`, `Кран KR-2`, `Причал B-4`, `Локомотив LOC-41`). Интеграция с АСУ РЖД и TOS смоделирована открытым контрактом. |
| **Матрица принятия решений** | • Динамический расчёт: выбор между «Ждать на рейде» (при коротком окне $\le 6\text{ч}$), «Махачкала» (при риске мели) и «Лихтер».<br>• Проверка 4 факторов реализуемости: осадка, причал/кран, нитка РЖД, тяга. | Фиксированные тарифы демереджа ($15\,000/сут) и перевалки ($12/т) зафиксированы как допущения. |
| **Pre-clearance (Smart Customs)** | • Честное криптографическое хеширование e-CMR манифеста через браузерный `crypto.subtle.digest('SHA-256')`.<br>• Формирование неизменяемой цепочки (`ledger-ready`). | Таможенное согласование симулировано локальной криптографической подписью без боевого шлюза ФТС/IRICA. |
| **ESG-калькулятор выбросов CO₂** | • Расчёт удельных выбросов по международной методике **GLEC Framework v3 / ISO 14083**.<br>• Сравнение мультимодального плеча (море + ж/д) с прямой автодоставкой еврофурами. | Средневзвешенные расстояния плеч маршрутов (Иран $\to$ Москва) фиксированы. |

## 3. Источники фактов кризиса на ВКМСК (Июнь 2026)

Сценарий **«Июнь 2026»** основан на открытых материалах официальных органов и информационных агентств:

1. **Пресс-центр Минтранса РФ (новость №12775 от 21.06.2026):**
   - *«О ситуации на Волго-Каспийском морском судоходном канале»*: после завершения весеннего паводка зафиксировано интенсивное отложение донных наносов (до 0.40–0.60 м) в сочетании с продолжительными сгонными ветрами северо-западных румбов (12–15 м/с) и исторически низким уровнем Каспийского моря.
   - [Официальный портал Минтранса РФ](https://mintrans.gov.ru/eye/press-center/news/12775).
2. **Интерфакс / ТАСС (июнь 2026):**
   - Распоряжения капитана морского порта Астрахань об ограничении движения и закрытии лимитирующего участка 151–155 км для судов с осадкой более 3.20–3.40 м (10–12 июня и с 19 июня 2026).
   - Скопление в очереди до 50 судов река-море на внешнем рейде в ожидании дноуглубительных караванов.

В системе эти данные вынесены в интерактивный ползунок «Наносы паводка» (0.10–0.55 м) и сценарий «Июнь 2026», позволяя воссоздать реальные условия кризиса.

## 4. Перечень допущений системы (`src/data/assumptions.ts`)

Все эксплуатационные константы явно изолированы с меткой `provenance: "assumption"`:
- **Паспортная проходная глубина ВКМСК:** 4.50 м (при проектном уровне Каспия −28.00 м БС).
- **Порог аннулирования слота РЖД:** 6.0 часов (при опоздании судна свыше этого времени нитка контейнерного поезда аннулируется диспетчером).
- **Запас безопасности под килем (UKC Safety Margin):** 0.50 м (порог безопасного прохода без лоцманского контроля).
- **Суточный демередж сухогруза:** \$15 000 / сутки (\$625 / час).
- **Штраф за простой вагонов-платформ:** 70 руб/вагон/час.
- **Глубина акватории порта Махачкала:** 6.80 м у причалов контейнерной зоны, глубина внешнего рейда ВКМСК (188+ км) — 9.50 м.
- **Точка стыковки колеи 1520/1435 мм:** ст. Астара (Азербайджан/Иран).
- **Коэффициенты эмиссии GLEC:** море — 14.2 г CO₂/т·км, электровоз РЖД — 18.5 г CO₂/т·км, автотранспорт Евро-5 — 62.0 г CO₂/т·км.

## 5. Архитектура проекта

```
src/
├── domain/                  # Чистая бизнес-логика (100% покрыта тестами Vitest)
│   ├── hydroProfile.ts      # Модель глубин, сгона, наносов и вероятности мели P10-P90
│   ├── scenarioDecision.ts  # Экспертная матрица решений (Ждать / Махачкала / Лихтер)
│   ├── slotSync.ts          # Синхронизация трёх дорожек (Судно ⇄ Порт ⇄ РЖД)
│   ├── underkeelClearance.ts# Расчёт запаса под килем (UKC)
│   ├── emissions.ts         # Углеродный след по GLEC / ISO 14083
│   ├── preClearance.ts      # SHA-256 Web Crypto ledger-штамп
│   └── chaos.test.ts        # Хаос-матрица (54 комбинации сценариев, осадок, ETA)
├── data/                    # Seed-данные, порты, флот, допущения
│   ├── assumptions.ts       # Все зафиксированные допущения (с источниками)
│   ├── ports.ts             # Порты Каспийского бассейна
│   └── vessels.ts           # Суда и манифесты
├── ui/                      # Компоненты интерфейса (Apple HIG, 100vh layout)
│   ├── App.tsx              # Корневой экран, координатор состояния
│   ├── Header.tsx           # Шапка: переключатели сценариев и режима Демо/Диспетчер
│   ├── CaspianMap.tsx       # Полноэкранная тёмная карта Leaflet с каналом ВКМСК
│   ├── HydroChart.tsx       # Интерактивный гидрографический график и скруббер
│   ├── DemoPanel.tsx        # Презентационный режим (крупные KPI, 1 карточка)
│   ├── SyncSlotPanel.tsx    # Панель Tripartite Sync-Slot (штриховка буферов)
│   └── CargoCard.tsx        # Цифровой двойник груза, ESG и Pre-clearance
└── styles/
    └── tokens.css           # Единый источник дизайн-токенов (Apple HIG)
```
